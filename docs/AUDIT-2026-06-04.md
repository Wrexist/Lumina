# Lumina — Complete-App Audit (2026-06-04)

Second full-app audit pass, on branch `claude/adoring-euler-yEDvq`. Complements
`docs/AUDIT-2026-06-03.md` (the R0–R9 remediation, now landed + CI-green).
This pass is organised by **dimension**; each finding has a severity and a
status. Severities: **P0** ship-blocker · **P1** important · **P2** polish.

Method: automated scans (`python`/`grep` over `Lumina/**`), screenshot review
(rendered via CI `ScreenshotTests`), and manual reading against
`docs/NAVIGATION.md` (the UX clarity charter).

## C. Accessibility — Dynamic Type  ⚠️ OPEN (R-A11Y-1)

| # | Severity | Finding |
|---|---|---|
| C1 | P1 | 8 fixed `.font(.system(size: N))` sites don't scale with Dynamic Type: `LuminaErrorState` (44), `LuminaEmptyState` (48), `TodayHubView` (28×2), `FriendDetailView` (56), `ReflectHubView` (56), `BigThreeBand` (36), `PlanetDetailSheet` (64). Hero numerals/icons stay fixed at the largest accessibility sizes. |

**Fix plan:** wrap with `@ScaledMetric` (or `.font(.system(size:).relativeTo)`)
so they scale, clamped with `.dynamicTypeSize(...DynamicTypeSize.accessibility2)`
where layout would break. Chart-wheel glyphs are radius-relative (correct, leave).

## F. Code hygiene  ✅ CLEAN

Scans found **zero** of: `try!`, `as!`, `print(`, `fatalError(` (non-test),
raw `.padding(<number>)`, hardcoded hex outside tokens. SwiftLint `--strict`
enforces these on every push. Backend: 67 tests green, `tsc` clean.

## G. Correctness / data integrity  ✅ (06-03) + this pass

- Chart math is backend-only (never LLM); transits + synastry are real
  cross-aspects with unit tests (incl. self-consistency: a chart against
  itself conjuncts every planet at orb ≈ 0).
- **Premium-thesis win:** the Today tab no longer fabricates transit copy
  from a day-of-year pool — it shows real transit→natal aspects, with an
  honest "a quiet sky today" empty state.

## H. Privacy / security  ✅ (carried)

On-device promises intact (palm photo never leaves; only feature numbers do);
no secrets in source; share-QR carries reduced `SharedBirthData`. Backend has
constant-time secret compare, rate limiting, body-size caps, security headers.
